# Конвенция: всплывающие элементы выбора (Окно 16, 03.08.2026)

Правило для любого следующего окна-разработчика этого проекта.

## Правило

Любой выбор времени, даты или списка с более чем парой значений - через свой темизированный виджет, **никогда** через нативный `<input type="date">` или нативный `<select>` с длинным списком опций.

Причина: браузер/ОС рисует нативные `<input type="date">` и `<select>` своим системным UI, не темой сайта - на телефоне это особенно заметно (Алихан заметил именно так, 30.07.2026, живой показ). Обычный `<select>` с 2-3 опциями (например переключатель роли) - это ОК, системная покраска короткого списка не режет глаз, кастомный виджет там избыточен.

## Готовые виджеты

- **Время** (`assets/crm-auth.js` - `renderTimeSelect(slotId, valueId, value)` / `timeSelectValue(id)`). Строит `.custom-select` (взаимодействие - `assets/mockup-crm.js`: `toggleCustomSelect`/`pickCustomSelectOption`).
- **Дата** (`assets/crm-auth.js` - `renderDateSelect(slotId, valueId, value)` / `dateSelectValue(id)`). Строит `.custom-date` - месячная сетка с переключением месяца (взаимодействие - `assets/mockup-crm.js`: `toggleCustomDate`/`renderCustomDateCalendar`/`pickCustomDateDay`/`shiftCustomDateMonth`).
- **Список** (уже было до Окна 16) - `.custom-select` напрямую в HTML/JS, тот же паттерн, что у времени, без временн**ы**х шагов.

## Как добавить новое поле выбора

1. В HTML вместо инпута - пустой контейнер: `<div id="myField-slot"></div>`.
2. В JS вызвать `renderTimeSelect('myField-slot', 'myField', defaultValue)` или `renderDateSelect(...)` аналогично.
3. Читать значение через `timeSelectValue('myField')` / `dateSelectValue('myField')` (не `.value` - у виджетов значение лежит в `dataset.value`, а не в нативном `value`).
4. Оба виджета кладут значение в том же строковом формате, что был у нативного инпута (`"HH:MM"` для времени, `"YYYY-MM-DD"` для даты) - остальной код (сравнения строками, отправка на сервер) не меняется.

## Формат id

`slotId` (контейнер в разметке) и `valueId` (сам виджет внутри) - РАЗНЫЕ id, иначе задвоятся (контейнер + вложенный div с тем же id). Конвенция этого проекта: `slotId = "${valueId}-slot"`.
